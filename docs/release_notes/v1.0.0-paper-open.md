# CEMP v1.0.0-paper-open

This release provides the public, reproducible CEMP source package for the
manuscript-associated open release.

Included assets:

- Source code under Apache-2.0.
- Public demo and manuscript-supporting CSV data under CC BY 4.0.
- Public model archive:
  `release_assets/cemp_public_model_assets.tar.gz`.
- Data manifest:
  `data/public_manifest.json`.
- Docker, Conda, deployment, API, data, and reproducibility documentation.

The model archive restores prediction model files to their runtime locations
when extracted at the repository root:

```bash
tar -xzf release_assets/cemp_public_model_assets.tar.gz -C .
```
